# Refig Implementation Plan

**Goal:** Build the local Figma-style desktop editor described in the spec.

**Spec:** `docs/superpowers/specs/2026-11-10-refig-design.md` (approved by the user 2026-11-11, "I approve everything"). The spec fixes architecture, file layout, IPC contract, format and test layers; this plan only orders the work.

**Execution:** native, in one session, no review stops (user instruction).

## Global Constraints
- Electron `contextIsolation: true, sandbox: true, nodeIntegration: false`; renderer talks to main only via `window.refig`.
- Projects are addressed by id; the renderer never sees a project path.
- Saves are atomic (tmp + fsync + rename). Nothing is written on import until validation passes.
- Runtime deps: `react`, `react-dom`, `fflate` only.

## Review Focus
1. Hand-edited or truncated `.refig` in the workspace: listed as damaged, never deleted. (Task 2 test)
2. Zip with unexpected or `..` entries, or oversized declared sizes: import rejects the file, batch continues. (Task 2 test)
3. Import of a project whose id or name already exists: nothing is replaced without a choice. (Task 2 test)
4. Save fails mid-write: old file intact, editor keeps the document and shows the error. (Task 2 + Task 5 tests)
5. Document with a parent cycle or dangling parent: rejected by `validateDocument`. (Task 2 test)
